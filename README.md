# E-commerce Core

Проект представляет собой ядро интернет-магазина с реализацией основных сущностей.

## Функционал

- Класс `Product` для представления товаров
- Класс `Category` для представления категорий товаров
- Автоматический подсчет количества категорий и товаров
- Загрузка данных из JSON файлов

## Установка и запуск

```bash
# Установка зависимостей
poetry install

# Активация виртуального окружения
poetry shell

# Запуск main.py
python main.py

# Запуск тестов
pytest

# Запуск тестов с покрытием
pytest --cov=src --cov-report=term-missing
