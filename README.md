## 🚀 Функционал проекта

### 1. Базовые классы (ДЗ 14.1)

#### Класс `Product`
Представляет товар с атрибутами:
- `name` — название товара
- `description` — описание товара
- `price` — цена товара
- `quantity` — количество на складе

#### Класс `Category`
Представляет категорию товаров с атрибутами:
- `name` — название категории
- `description` — описание категории
- `__products` — приватный список товаров в категории

**Атрибуты класса:**
- `category_count` — общее количество категорий
- `product_count` — общее количество товаров

### 2. Инкапсуляция и свойства (ДЗ 14.2)

#### Класс `Product`
- Приватный атрибут `_price`
- Геттер `price` — возвращает цену
- Сеттер `price` — проверяет, что цена положительная, иначе выводит сообщение

#### Класс `Category`
- Приватный атрибут `__products`
- Метод `add_product(product)` — добавляет товар в категорию
- Геттер `products` — возвращает строку с товарами в формате:

Название продукта, X руб. Остаток: X шт.

#### Класс-метод `new_product`
- Создает экземпляр `Product` из словаря с данными

### 3. Магические методы (ДЗ 15.1)

#### `__str__` для Product
```python
str(product)  # "Смартфон, 50000.0 руб. Остаток: 10 шт."

__str__ для Category
str(category)  # "Электроника, количество продуктов: 30 шт."

__add__ для Product
Складывает два товара, возвращая общую стоимость на складе:
product1 + product2  # (цена1 × кол-во1) + (цена2 × кол-во2)


4. Наследование (ДЗ 16.1)

Класс Smartphone (наследник Product)

Дополнительные атрибуты:

efficiency — производительность
model — модель
memory — объем встроенной памяти (ГБ)
color — цвет
Класс LawnGrass (наследник Product)

Дополнительные атрибуты:

country — страна-производитель
germination_period — срок прорастания
color — цвет
Ограничения сложения

Можно складывать только товары одного класса
При попытке сложить разные классы возникает TypeError
Ограничения добавления товара

В категорию можно добавлять только объекты Product или его наследников
При попытке добавить другой тип возникает TypeError

📦 Установка и запуск

Требования

Python 3.9+
Poetry
Установка

bash
# Клонирование репозитория
git clone https://github.com/Murat523344/ecommerce-project.git
cd ecommerce-project

# Установка зависимостей
poetry install --no-root

# Активация виртуального окружения
poetry shell
Запуск

bash
# Запуск программы
python main.py

# Запуск тестов
pytest -v
